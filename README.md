# 🇮🇳 Government Services AI Chatbot

An AI-based chatbot website that provides information about Indian government schemes and services. Users can ask questions about schemes, eligibility, required documents, and application procedures.

## 📌 Project Overview

The Government Services AI Chatbot is developed using **Python and Flask**. It provides a simple web-based chat interface where users can interact with the chatbot and get information about various government schemes.

The chatbot currently supports:

- PM-KISAN
- Ayushman Bharat
- PM Awas Yojana
- Beti Bachao Beti Padhao
- Digital India

## ✨ Features

- 🤖 Interactive AI-style chatbot
- 🇮🇳 Government scheme information
- 📋 Eligibility information
- 📄 Required documents
- 📝 Application procedure
- 💬 Simple and user-friendly chat interface
- 📱 Responsive web design
- ⚡ Flask-based backend
- 🔍 Supports different spellings such as PM-KISAN, PM KISAN and PMKISAN
